\# AI Workforce Management System



A full-stack workforce management web application designed to manage employees, departments, projects, tasks, and workforce performance through role-based Admin, Manager, and Employee portals.



\## Overview



The AI Workforce Management System provides a centralized platform for managing workforce operations.



The system includes role-based access for:



\- Administrator

\- Manager

\- Employee



It also includes an AI-powered employee recommendation concept that uses workforce information such as performance, workload, and department data to help managers identify suitable employees for task assignment.
